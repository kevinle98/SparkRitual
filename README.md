# SparkRitual ⚡🖤

A fast, modern deck builder and analytical tool for Magic: The Gathering.

SparkRitual is a high-performance web application designed for Magic: The Gathering players and brewers to construct, manage, and analyze Commander decks seamlessly. Built with vanilla JavaScript and powered by the Scryfall API, it offers lightning-fast card searching, real-time deck stats, and interactive test-hand simulations.

Features
✨ Advanced Deck Construction & Management: Create, save, and manage multiple Commander decks locally or synced in the cloud. Supports solo commanders and automated legal pairing for Partners, Backgrounds, and Doctor's Companions.
✨ Real-Time Analytics & Color Identity Validation: Automatically validates cards against your commander's color identity, flags illegal inclusions, and calculates mana curves, average mana value (MV), and a heuristic power bracket estimate (Core, Upgraded, Optimized, cEDH) complete with Game Changer tracking.
✨ Intelligent Card Search: Search the Scryfall database constrained automatically by your commander's color identity and Commander legality, featuring instant ranking and duplication checks.
✨ Interactive Playtest Simulator: Test opening hands on the fly, draw cards from your randomized library, and preview opening draws instantly with dynamic scaling.
✨ Flexible View Modes & Printing Management: Switch between detailed list views and responsive visual grid modes (with optional card stacking). Easily swap between alternative card printings, sets, and artworks.
✨ Import & Export Support: Seamlessly import and export standard decklists (compatible with MTG Arena, MTGO, and popular text formats).
✨ Ambient Background Music: Optionally attach YouTube background tracks to your decks to set the tone while you brew.
